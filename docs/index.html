The headline

Patterns across the 100 apps

Bottom line: most apps are easy to connect. The hard ones are concentrated in finance, ads and ecommerce, and what blocks them is usually a vendor approval or a customer-only account, not price.

66/100

OAuth 2.0 is the default login

45 apps also take API keys and 33 take personal or bot tokens. 30 apps have no OAuth at all, so each user pastes a key instead of clicking Connect.

73/100

Most apps are self-serve

Dev, Infra & Data and Productivity & PM: 10 of 10. Finance & Fintech: 4 of 10. A developer gets keys alone from a free tier (54), a trial (17) or open source (2).

10 of 36

Top blocker: waiting on a vendor review

Developer tokens, app review and production-key approval (Google Ads, Meta, QuickBooks, Amazon). Next: customer or partner accounts (6) and paid plans just to test (6).

84/100

Official MCP servers are now normal

Many launched in 2026. The agent's first draft, written from memory, guessed 48. So a toolkit's value is managed auth and well-built tools.

Bottom line: write a fast first draft, check it cheaply, and spend real research only where a check fails. Every change is logged with the check that caused it, a source and a quote.

What the agent uses

  • Claude Opus 5.5 with web search and web fetch
  • Headless Chrome for JavaScript-built docs
  • The official MCP Registry API
  • Claude and OpenAI connector directories
  • Composio's composio_search and firecrawl toolkits (headless mode)

Where a human was needed

  • Which product? "Paygent Connect" matches two companies. Only the requester can say which.
  • Rule calls. Docs-only MCPs don't count. Sandbox-only keys count as "approval".
  • False matches. LinkedIn's ChatGPT app is profile lookup, not Ads.
  • Unreadable pages. Lark's and HighLevel's docs stay empty even in Chrome.
  • Customer-only APIs. DealCloud, Gladly and PitchBook can't be tested without a paying account.

How this run was done

  • Claude Code (Opus 5.5) did the research steps as the agent, using the prompt and schema in the repo.
  • The headless agent (Claude API + Composio tools) is in the repo and checks out against the SDKs. It was not run end to end because no API keys were available.
  • All checks are plain Python and re-run in CI on every push.
